Passo 1 — Baixar Template

Baixe o arquivo Excel modelo, preencha com as cotações e faça o upload no Passo 2. Cada linha representa uma cotação. Para atualizar um registro existente, preencha a coluna id com o ID exibido no portal. Deixe id vazio para criar um registro novo. As colunas date e response_received_at aceitam datas em DD/MM/AAAA ou AAAA-MM-DD; deixe em branco se não souber.
